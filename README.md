# My First Portfolio Website

This is my first personal portfolio project built using **HTML, CSS, and JavaScript**.  
It showcases my skills, projects, and contact information in a simple and responsive design.  

### Features
- Clean and responsive layout
- About Me section
- Projects showcase
- Contact form with basic validation
- Smooth navigation and animations

### Purpose
I created this portfolio to practice front-end development and share my work with others.  
It is my first step towards building a professional developer profile.
